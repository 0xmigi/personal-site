firestarter is a [TypeScript SDK](https://github.com/0xmigi/firestarter-sdk) for Pipe Network decentralized storage — simple, explicit, and framework-agnostic — plus the interactive demo linked above that exercises it.

The SDK wraps accounts, uploads, downloads, sharing, and PIPE/SOL balance management into straightforward client calls; the demo adds real-time upload progress and file management on top. Part of the same storage-layer research thread that later became [storage-arena](/projects/storage-arena).
